# 单向波时间序列研究：阶段性结论

从声明的一阶时间序列 eta1(t)，经有限水深线性色散恢复母波波数，使用已有
无 Stokes correction 的 GL 核重构束缚波时间序列，这条正向路线已经跑通，
并有 Wolfram 代数检查、MATLAB 空间/时间执行器一致性和 OW3D 场比较证据。
目前可作为已测试范围内的研究工具继续使用，不宜概括为所有单向时间序列问题已解决。

方向性联合输入的后续扩展已揭示适用边界：近中心/沿主方向通常较好，远横向
强相消点可能严重失准，方向性eta20在部分深水算例中也有大误差。
不能将首例及五点小范围成功推广为通用方向性重构认证；见
`../directional_wave_data/EXTENDED_SWEEP.md`。

| 内容 | 当前证据 | 尚未覆盖 |
|---|---|---|
| eta22 | kh=1 的小/较大陡度与 GL/MF12/VWA/Walker；kh=0.5 小陡度 | 全水深、频谱、陡度矩阵 |
| eta20 | 非零差频 GL 诊断，与二阶 MF12；输出上限 0.5 和 3 omega_p | 严格零频均值、完整平均流；不能把频率带视为严格阶次分离 |
| eta33 | 无修正 GL4/6/8、VWA、Walker；不计算 MF12 三阶 | GL 求积收敛、大陡度下三阶与高阶谐波贡献的分离 |
| psi11、psi22 | 自由面势 psi=phi(x,eta,t)，同 eta1 输入，kh=1 两种陡度 | psi20、psi33 和任意垂向位置的体势 |
| 实现 | 逐对/逐三元组参考执行，保留真实波数与频率组合 | 高效固定复杂度时间 FFT 算法、性能认证 |
| 输入 | 已知或已分离一阶输入；OW3D 四相位第一谐波作为近似 | 从实测总波面反演 eta1；四相位不等于纯扰动一阶 |

必须继续区分：计算实现的一致性、GL 求积误差，以及纯固定阶次重构与非线性
OW3D 谐波记录的差异。后两者不能仅凭曲线接近就视为已经分离。

推荐下一步：扩展至自由面势 psi33，并同步检查 eta33/psi33 的求积收敛；保持
不使用三阶 MF12、不加入 Stokes 修正和不对 OW3D 调参的边界。随后再扩展水深
和频谱矩阵。不是立即开展总波面反演或声称通用高效算法。

# Green--Laplace Python

Python implementation of finite-depth Green--Laplace bound-wave
reconstruction. The package has two user-facing paths:

- a real directional first-order snapshot `eta1(x,y)` to spatial `eta11`,
  `psi11`, `eta22`, `psi22`, `eta33`, and `psi33`;
- a uniformly sampled single-direction record `eta1(t)` to `eta11(t)` and
  `eta20(t)`, `eta22(t)`, and `eta33(t)`.

Both paths use prescribed Gauss--Laguerre nodes, filtered fields, pointwise
products and FFTs.  The implementation follows the no-Stokes MATLAB graph.

## Environment and dependencies

Runtime requirements:

- CPython 3.10 or newer;
- NumPy 1.24 or newer;
- a 64-bit Python installation for practical two-dimensional fields.

The runtime package does not require SciPy, MATLAB, Mathematica, a compiler,
or a Python FFT extension. It uses NumPy's double-precision complex arrays and
FFT implementation.

Development and test requirements:

- pytest 8 or newer, installed by the optional `test` dependency;
- MATLAB R2022b with base MATLAB only if the committed MATLAB--Python fixtures
  need to be regenerated. MATLAB is not required to install or run the Python
  package.

The automated tests run on Python 3.10 and 3.12.

## Installation

From the repository's `python/` directory:

```bash
python -m pip install .
```

For an editable development installation on Windows:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m pytest
```

On Linux or macOS, activate the environment with
`source .venv/bin/activate` and run the same `pip install -e ".[test]"`
command.

## Directional spatial field

```python
from green_laplace import reconstruct_directional_field

result = reconstruct_directional_field(
    eta1_xy,
    lx=Lx,
    ly=Ly,
    depth=h,
    gravity=9.81,
    order=3,
)
eta22 = result.components["eta22"]
psi22 = result.components["psi22"]
eta33 = result.components["eta33"]
psi33 = result.components["psi33"]
```

The real spatial input is interpreted using the forward-x convention
`exp(i*(kx*x+ky*y)-i*omega*t)`.

## Single-direction time record

```python
from green_laplace import reconstruct_unidirectional_timeseries

result = reconstruct_unidirectional_timeseries(
    eta1_t,
    time,
    depth=h,
    gravity=9.81,
    order=3,
    modal_points=(2048, 4096, 8192, 16384, 32768, 65536),
    relative_tolerance=1e-3,
)
eta20 = result.components["eta20"]
eta22 = result.components["eta22"]
eta33 = result.components["eta33"]
```

The time executor evaluates the Green--Laplace response directly on a
one-dimensional `q`-modal grid. It does not use an auxiliary spatial domain.
The default modal ladder doubles the grid until both `eta22` and `eta33`
change by no more than `0.1%`, or until the declared ladder is exhausted.
See the [modal identity and refinement checks](docs/modal_resolvent_prototype.md)
and the [random-wave HOS comparison](docs/random_hos_modal_comparison.md).

The tests include deterministic fields generated by the MATLAB FFT--GL
implementations. `tools/generate_matlab_fixtures.m` rebuilds the fixtures from
the MATLAB sources in this repository and records their source revisions.

The spatial and temporal tests compare each implemented component with frozen
MATLAB FFT--GL output. The fixtures retain their MATLAB source revisions.
